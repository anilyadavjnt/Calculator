# 🧮 Calculator iOS App

A simple and user-friendly **Calculator iOS application** built using **Swift and UIKit**. This project demonstrates fundamental iOS development concepts including UI design, Auto Layout, button interactions, and calculation logic.

## 📱 Features

* Basic arithmetic operations
* Addition, subtraction, multiplication, and division
* Decimal number support
* Clear/reset functionality
* Responsive calculator UI
* Clean and simple interface
* Handles user input through button actions
* Supports different iPhone screen sizes

## 🛠️ Technologies Used

* **Swift**
* **UIKit**
* **Auto Layout**
* **Storyboard**
* **Xcode**
* **iOS SDK**

## 🏗️ Architecture

The application follows a simple UIKit-based structure with separate handling for:

* UI components
* Button actions
* User input
* Calculation logic
* Display updates

## 🚀 Getting Started

### Requirements

* macOS
* Xcode
* iOS Simulator or physical iPhone
* Swift

### Installation

1. Clone the repository:

```bash
git clone https://github.com/anilyadavjnt/Calculator-iOS.git
```

2. Open the project in Xcode.

3. Select an iPhone Simulator or connected device.

4. Build and run the application.
